# Changelog

Notable changes to this project are recorded here. The repository has not yet
made a published release.

## Unreleased

- Added Supabase email/password authentication, email OTP verification, password
  recovery, and protected workspace access.
- Added a Cloudflare Worker API and a vanilla JavaScript static application.
- Added a bundled 230-company implementation catalog and three clearly marked
  demo job records.
- Added user-scoped browser-local settings and IndexedDB storage for a base
  resume; resume contents are not uploaded to the Worker.
- Added Node.js tests, a static asset build, and a Cloudflare dry-run verify
  command.
- Added contributor, security, conduct, roadmap, and project setup guidance.
